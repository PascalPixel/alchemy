# The Lost Age: graphics

The Lost Age's pictures, each folder with the `.s` files that only place them:
the battle backgrounds (`battle_backgrounds/`), the battle effects' sheets
(`battle_effects/`), the field effects (`field_effects/`), the monsters, the
sprites, the tile sets, the font, the staff credits' font (`credits/`), the
palettes (`palettes/`), Lucky Dice and Lucky Wheels, the Title, the World Map
and the User Interface's pictures (`ui/`). [Graphics](../../../tbs/src/graphics/README.md)
explains how they are built and drawn.

## What differs from The Broken Seal

- Some picture placements are still with their code bank, mixed with other
  data or awaiting this game's own pass (`battle/d012cc74.s`,
  `field/event_commands/glint.s`).
- This game's copies of pictures The Broken Seal also has are its own files
  under its own resource numbers.
- `ending/`, `field/`, `lettering/` and `summon/` hold pictures The Broken
  Seal has no folder for, named for what they hold until this game's own pass.

### Map, surface, and Cloak

Recommended shared layouts:

```c
struct MapCell {
    u16 metatile_and_flags;
    u8 collision_code;
    u8 attribute_b;
};

struct MapLayer {
    struct MapCell *cells;
    u8 unknown04[0x2c];
};

struct MapState {
    u8 unknown000[0x130];
    struct MapLayer layers[4];
};

struct WorldPosition {
    s32 x;
    s32 y;
    s32 z;
};
```

Facts:

- A map cell is four bytes and a layer has stride 0x30.
- Four layers begin at map-state `+0x130`; ordinary object collision accepts
  layers 0–2.
- Cell `+0x02` is the collision/terrain behavior code.
- Cell `+0x03` has a different interpretation on the world map; keep it
  neutral in a shared type.
- `08012204` samples a four-bit surface code, using a priority layer then a
  fallback layer and defaulting to 7.
- `080122ac` accepts surface codes 5–12, returning 0 for success and -1 for
  blocked.
- `080122c8` classifies the raw surface code separately.
- Ability `0x92` is Cloak. `08099678` monitors collision code `0xfb` and queues
  `0x2092` to cancel Cloak when the player leaves a shadow tile.
- Runtime `+0x17e` is the queued field command; global `+0x24c` is a signed
  16-bit Cloak-active flag.

Scratch-exact regions:

- `08012038` 64 bytes
- `08012078` 60
- `08099678` 192
- `08012204` 168
- `080122ac` 26
- `080122c8` 104
- `08099738` 216
- `08099810` 40

Critical codegen cautions:

- Preserve `(u32)&Data_03001ebc - 76` in `08099678`. A direct
  `Data_03001e70` reference grows the region by four bytes and changes 35
  halfwords.
- Keep the Cloak flag signed `s16`; `u16` changes `ldrsh` to `ldrh`.
- Preserve the unsigned range expression in `080122ac`.
- Do not turn the two surface samples into a loop, change signed rounding to
  shifts, or add `volatile`.

# Python tooling dependencies.
#
# pycparser is the structural oracle behind tools/c_structure.py, which
# alchemist.ts consults to decide whether a source reordering is legal.
# alchemist.ts's own line-and-regex model could not represent C's actual
# structure, and each place it guessed wrong produced source that still
# compiled to fewer differing bytes -- so the byte-diff gate accepted a
# variant that meant something different from what was written. A real parse
# answers those questions instead. (It is also the parser m2c uses for its C
# context files, so it is already in this project's tooling lineage.)
pycparser>=2.21
